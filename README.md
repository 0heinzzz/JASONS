# Mein Super-Projekt

Dies ist ein Beispielprojekt, um die Welt zu verbessern. Es sortiert automatisch Ihre Dateien nach Wichtigkeit mithilfe von KI.

## 🚀 Installation

Stellen Sie sicher, dass Sie Python 3.8 oder höher installiert haben.

1.  Klonen Sie das Repository:
    ```bash
    git clone [https://github.com/beispielnutzer/mein-super-projekt.git](https://github.com/beispielnutzer/mein-super-projekt.git)
    ```
2.  Wechseln Sie in das Projektverzeichnis:
    ```bash
    cd mein-super-projekt
    ```
3.  Installieren Sie die Abhängigkeiten:
    ```bash
    pip install -r requirements.txt
    ```

## ⚙️ Verwendung

Um das Skript auszuführen und Ihre Dateien im Ordner `/pfad/zu/dateien` zu sortieren, verwenden Sie den folgenden Befehl:

python sortiere_dateien.py /pfad/zu/dateien
